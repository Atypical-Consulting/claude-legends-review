How Legends Review Works

1

Independent Review

Each legend reviews the code through their unique lens without seeing the others.

2

Debate

They read each other's reviews and argue in character. Challenges, defenses, concessions.

3

Consensus

Final ratings, unified actions, and three hard truths that survived the debate.
